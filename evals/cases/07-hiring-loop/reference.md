# Running the Engineering Hiring Loop

## When to use this skill

You are scheduling, running, or debriefing an engineering candidate.

## Loop stages (in order)

1. **Recruiter screen** (30 min) — Priya.
2. **Hiring manager intro** (45 min).
3. **Take-home** (4 hour cap; $200 paid for senior+ roles).
4. **Onsite** — 4 sessions, 1 day:
   - Coding pair (90 min)
   - System design (60 min; senior+ only)
   - Cross-functional / behavioral (45 min)
   - Founder chat (30 min; leveling)
5. **Debrief same day** with all interviewers.
6. **Decision within 48 hours** of the debrief.

## Hard rules

- **Do NOT skip the take-home.** No exceptions, including for ex-FAANG referrals. The two prior exceptions caused incident-level bad hires.
- **Do NOT exceed 14 days** from recruiter screen to offer. Loops that drag lose candidates.

## Materials

## After offer

Standard offer process applies once the loop completes. The hiring manager owns the close.
