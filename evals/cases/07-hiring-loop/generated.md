# Running the engineering hiring loop

## When to use this skill

Apply this skill whenever:

- Scheduling or progressing an engineering candidate through interviews
- A recruiter, hiring manager, or interviewer asks about loop structure, stages, or timing
- A referral (including ex-FAANG) requests an expedited or modified path
- Setting up or reviewing scorecards and debriefs
- Auditing whether a loop met the time and process requirements

## Hard rules

- NEVER allow a candidate to skip the take-home assessment, including ex-FAANG referrals or any other referral source.
- DO NOT let total loop duration from recruiter screen to offer exceed 14 days.
- DO NOT run the system design interview for candidates below senior level.
- DO NOT delay the post-onsite decision beyond 48 hours after debrief.

## Loop stage sequence

Run all engineering candidates through these five stages in order:

| # | Stage | Duration | Notes |
|---|---|---|---|
| 1 | Recruiter screen | 30 min | Owned by Priya |
| 2 | Hiring manager intro | 45 min | — |
| 3 | Take-home assessment | 4 hr cap | Mandatory; paid $200 for senior and above |
| 4 | Onsite (4 sessions, single day) | See onsite table | All four sessions same day |
| 5 | Debrief + decision | Same-day debrief | Decision communicated within 48 hours |

### Onsite sessions (single day)

| Session | Duration | Applies to |
|---|---|---|
| Coding pair | 90 min | All candidates |
| System design | 60 min | Senior and above only |
| Cross-functional / behavioral | 45 min | All candidates |
| Founder chat | 30 min | All candidates (used for leveling) |

## Take-home policy

1. Cap candidate effort at 4 hours; communicate the cap explicitly.
2. Pay $200 for take-homes completed by candidates interviewing for senior or above roles.
3. Below senior, the take-home is still required but unpaid under current policy.
4. If a referrer or candidate pushes to skip the take-home, decline and point them at the hard rule above. There are no exceptions.

## Timing requirements

- Track elapsed days from the recruiter screen date to the offer date for every candidate.
- The full loop must close in fewer than 14 days.
- If scheduling slips threaten the 14-day window, escalate to the hiring manager and Priya immediately rather than letting the loop drift.
- Hold the debrief on the same day as the onsite and issue the decision within 48 hours of that debrief.

## Workflow checklist

- [ ] Recruiter screen scheduled (30 min, Priya)
- [ ] Hiring manager intro scheduled (45 min)
- [ ] Take-home sent with 4-hour cap; payment of $200 confirmed if senior+
- [ ] Onsite booked as a single day with all four sessions
- [ ] System design included only if candidate is senior+
- [ ] Debrief calendared for the same day as onsite
- [ ] Decision sent to candidate within 48 hours of debrief
- [ ] Total elapsed time from screen to offer is under 14 days
- [ ] Scorecards completed in the Notion template

## Documentation and templates

- Canonical loop documentation lives in Notion under Hiring → Eng Loop 2026.
- The scorecard template is maintained in the same Notion location; use it for every interviewer write-up.
- When updating process, update the Notion page first, then communicate changes — do not rely on chat history as the source of truth.

## Examples

- An ex-FAANG staff engineer is referred by a founder and asks to skip the take-home. Response: decline, send the take-home with the 4-hour cap, and confirm the $200 payment since the role is senior+.
- A mid-level backend candidate is being scheduled. Response: include coding pair, behavioral, and founder chat in the onsite; omit system design.
- A loop is on day 12 with the onsite still unscheduled. Response: escalate to the hiring manager and Priya to compress scheduling so the offer can land before day 14.
